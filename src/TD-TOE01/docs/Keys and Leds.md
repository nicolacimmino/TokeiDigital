**LEDs**
CHRONO1, CHRON2, CHRONO3 timer in chronograph mode
STOP1, STOP2, STOP3 timer stopped
T/O1, T/O2, T/O3 timer timed out
RUN1, RUN2, RUN3 timer running
SEL1, SEL2, SEL3 times selected for display and input
PRG Program mode
PRE Preset mode
NUM Numeric input mode
MUTE Buzzer is muted
6 digits 7 segment display

Buttons

SEL/+ Changes the selected timer for control and input, increments AD in PRG mode
START/STOP/AD Starts, stops, halts the current selected timer, address in PRG mode
LAP/RESET/DA Current time lap or reset, data in PRG mode
FN Function key, selects alternate function for other keys
4x4 Keypad: 0-F in PRG mode, 0-9 in NUM mode, +10,+5,+1,-1 for H,M,S when not in NUM, second functions: NUM, PRE, PRG, MUTE
