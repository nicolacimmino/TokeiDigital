# OE Timer — Quick Start Guide

This guide explains the basic operations to start using the timer immediately.  
Advanced programming and memory features are not covered here.

The device has three independent timers (T1, T2, T3) that can run in parallel.  
Use **SEL** to choose which timer you control.

---

## Selecting a Timer

Press **SEL** until the LED of the desired timer (T1, T2, T3) is on.

The display always shows the currently selected timer.  
All inputs affect only the selected timer.

---

## Setting a Countdown Time (Numeric Mode)

1. Press **FN + NUM** to enable numeric input (NUM LED on)
2. Make sure **PRE** and **PRG** are off
3. Enter the time using digits (HHMMSS)
4. Press **START**

The timer starts counting down and the **RUN** LED turns on.

> Note: Entering `00:00:00` starts chronometer mode instead.

---

## Setting a Countdown Time (+ / − Mode)

1. Press **FN + NUM** until NUM is off
2. Make sure **PRE** and **PRG** are off
3. Use the keypad columns to adjust:
   - +10 / +5 / +1 / −1 for hours, minutes, seconds
4. Set a time different from `00:00:00`
5. Press **START**

The timer starts counting down and the **RUN** LED turns on.

---

## Starting from a Preset

1. Press **FN + PRE** (PRE LED on)
2. Press a digit (0–9) to load a preset
3. The preset time appears on the display
4. Press **START**

The timer starts counting down.

You may edit the loaded time before pressing START.

---

## Timer Operation

### Start / Pause / Resume

- Press **START** to start the timer
- Press **START** again to pause (HALT)
- Press **START** again to resume

### Reset

- Press **LAP / RESET** while stopped to restore the start value

### Lap

- Press **LAP / RESET** while running to freeze the display
- Press again to return to live time

### Timeout

When the timer reaches zero:
- The buzzer sounds for a few seconds
- The **T/O** LED turns on

Press **RESET** to reload the previous value  
or enter a new time.

---

## Chronometer Mode (Count Up)

1. Set the time to **00:00:00**
2. Press **START**

The timer counts up and the **CHRONO** LED turns on.

Controls:

- START → pause / resume
- LAP → freeze display
- RESET (while stopped) → back to 00:00:00

---

## Storing a Preset

1. Set a time normally
2. Press **FN + PRE**
3. Hold a number key (0–9)
4. The preset number flashes to confirm

Preset is saved.

---

## Muting the Buzzer

Press **FN + MUTE**

The **MUTE** LED turns on when the buzzer is muted.

Press again to enable sound.

---

## Memory Programming (Advanced)

1. Press **FN + PRG**
2. Use:
   - AD to enter address
   - DA to enter data
   - + to go to next address
3. Press **FN + PRG** to exit

Timers are inactive while in PRG mode.
