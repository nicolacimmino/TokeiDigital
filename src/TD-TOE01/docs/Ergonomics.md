The control panel is designed for comfortable use by right-handed users while remaining usable for left-handed users.  
The display and status LEDs are placed on the left side, while the keypad is on the right side. This allows the user to read the display without obstruction while operating the keys.

The intended grip is with the left hand stabilizing the device, using the thumb and middle finger to hold the unit while the left index finger operates the SEL and FN keys located on the left side.  
The right hand is used to operate the keypad, typically with the index finger pressing one key at a time.

The FN key is placed near the SEL key on the left side so that modifier combinations can be performed using the left index finger on FN while the right hand presses the desired key on the keypad. This avoids the need to cross hands over the display and allows two-handed operation without changing grip.

Keys that are frequently used during normal operation (numeric keys, +/- keys, start/stop, lap/reset) are reachable with the right hand alone, while mode and modifier keys are grouped on the left side for the left hand.

This layout keeps the display unobstructed during operation, minimizes hand movement, and follows the typical interaction pattern of calculators, lab instruments, and vintage front-panel devices, where the readout is separated from the input area and modifier keys are placed opposite the main keypad.
